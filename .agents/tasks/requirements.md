# SIMShift first working vertical slice — requirements

## Summary

Build a runnable Python 3.11 CLI under `simshift-agent/` that proves this causal path: seeded synthetic cohort observation → deterministic capability filter → **real Strands Decider 2B choice** → matching directly invoked Strands-registered tool → deterministic policy/approval gates → optional virtual-only eUICC/eIM/IPA transition → separate registration and application-telemetry checks → one post-evidence explanation. The slice covers `BR_PROFILE` and `OFFLINE`; it prioritizes causal tool routing and safety evidence over UI polish. Bedrock may explain evidence but may not select or authorize a tool. A standalone `patterns/capability_aware_router/` must demonstrate the same pattern outside telecom.

Status at design time: **IMPLEMENTED:** no production slice. **VERIFIED:** the pinned Decider wire contract and Strands 1.61.1 direct-tool/Bedrock APIs. **OBSERVED:** one local invocation of the pinned real Decider app. **SIMULATED:** every telecom entity, approval, action, check, and outcome. **UNVERIFIED:** Bedrock account/model availability, AWS deployment, GPU behavior, domain accuracy, latency, and cost. Runtime, traces, and docs must preserve these labels independently per component.

Assumptions: the cohort is the orchestration unit; the first interface is a CLI; Brazil has a fictional pre-established bootstrap management channel independent of the failing active profile; `--approval granted|denied` is a scripted **simulated approval intent**, not a pre-existing grant, and is materialized only after the exact proposal is shown/traced; and the provisional confidence floor `0.20` is an uncalibrated routing policy, not a safety claim.

## Functional Requirements

1. **Seeded fixtures and complete effects.** Ship strict JSON fixtures for exactly `BR_PROFILE` (default seed `20261018`) and `OFFLINE` (`20261019`). Each fixture contains separately typed observable state, policy metadata, and evaluator-only truth. It defines an occurrence-indexed deterministic result for every action that can be dispatched, including evidence additions, registration/telemetry probabilities, and profile-delivery outcome. The exact v1 schemas and complete fixture values are normative in `docs/simulation-scope.md`.
2. **Hidden-truth isolation.** Only `VirtualFleetEngine` may resolve `EvaluatorTruth`. Decider/Bedrock projections are constructed from `ObservableIncident` by positive allowlist, never by deleting fields from a raw fixture. Leakage means any evaluator-only key/path, `HiddenCause`, serialized `EvaluatorTruth`/`ActionEffect`, or the fixture's unique non-overlapping evaluator canary reaches a model request, tool argument/result, trace, log, or explanation. Values independently defined by public schemas—such as `Action` and `EvidenceCode` strings—are allowed when produced through public DTOs.
3. **Capability filtering and deployment cardinality.** Start from the six stable actions `retry_connection`, `try_allowed_operator`, `investigate_device`, `investigate_data_path`, `evaluate_profile_change`, and `escalate_or_wait`. A deterministic filter returns 0–255 eligible options and every removed option with a reason. The router receives trusted `num_slots` from verified health/manifest data and constructs a Decider question only when `2 <= option_count <= min(255, num_slots)`. With fewer than two, record `NoDecision`; above capacity, return `NoDecision(UNSUPPORTED_CHOICE_CARDINALITY)` without calling Decider or dispatching. SIMShift may directly choose `escalate_or_wait` only when its domain filter kept that label eligible. Never add, silently drop, or fabricate an option.
4. **Real Decider only in runnable code.** The CLI uses the verified `POST /v1/systemone` contract through the canonical strict HTTP client in `patterns/capability_aware_router/decider_client.py`. A SIMShift wrapper adds projection, retries, manifest/health consistency checks, and trace metadata; it does not duplicate parsing or confidence logic. Fake Deciders exist only under `tests/` and are dependency-injected only by tests.
5. **Decision policy and causal Strands routing.** Trace `model_choice` and `effective_choice` separately. With confidence at or above policy floor they match; below the default `0.20`, effective choice becomes `escalate_or_wait` with reason `LOW_CONFIDENCE`. Every effective label maps through a fixed allowlist to exactly one `@tool` registered on a `strands-agents==1.61.1` `Agent`, invoked via `agent.tool.<exact_name>(...)`. Bedrock makes zero calls before or during dispatch. `evaluate_profile_change` prepares a proposal only.
6. **Uniform tool contract and current-state lookup.** All six tools have exactly keyword-only `incident_id: str` and `observation_revision: int` arguments. Run-scoped `ToolServices` resolves current typed state, rejects unknown incidents and stale revisions, and returns a strict `ToolResult`. Telecom policy metadata may be exposed only to proposal preparation; evaluator truth remains accessible only inside `VirtualFleetEngine`.
7. **Bounded orchestration.** Enforce at most four decision iterations, two retries after the initial Decider attempt, two connection retries total, one profile transition total, one dispatch per decision, and one explanation call. No recursion or action retry follows a simulated profile timeout/failure. A reached bound produces a traced safe escalation or typed dependency failure.
8. **Proposal-bound approval, pure gates, and atomic transition commit.** `ProfileTransitionProposal` is prepared and traced before an `ApprovalGrant` exists. A scripted CLI approval intent is then converted into a simulated grant bound to the exact run, proposal, incident, source profile, target profile, and status; every field mismatch, stale grant, or consumed grant is denied. Capability, reachability, authorization, approval, and risk gates are deterministic and pure. Evaluate once as preview, then acquire the incident lock, reread state, and evaluate again without mutation. On final denial, store/return a `BlockedProposalAudit`; create no command, transition, reservation, or approval consumption. On pass, atomically reserve deterministic `(run_id, transition_id)`, consume the bound approval, and create one transition record containing `REQUESTED → VALIDATED → APPROVED`. Duplicate proposals/dispatches return the existing audit/record without mutation.
9. **Virtual eUICC/eIM/IPA only.** The simulator alone may advance an approved record through `SENT → ACKNOWLEDGED → ENABLED → VERIFYING → SUCCEEDED`; delivery may instead end `TIMED_OUT` or `FAILED`. At `ENABLED`, it atomically disables the prior synthetic profile and enables the target while preserving exactly one active profile. No module may call a carrier, modem, SM-DP+, eUICC, eIM, IPA, or telecom control-plane endpoint.
10. **Independent recovery checks.** After every state-changing retry/operator/profile action, emit a fresh registration check and a separate telemetry/ACK check, even when registration fails. `service_restored` is true only when both meet fixture thresholds. `ENABLED`, registration alone, or a model statement cannot mark recovery.
11. **Required scenario behavior.** `BR_PROFILE` filters operator reselection, permits profile evaluation while its bootstrap channel is fresh, blocks without approval, and under the approved deterministic profile path can reach `SUCCEEDED` only after both checks pass. `OFFLINE` filters retry, operator reselection, and profile evaluation; a forced policy proposal is denied for `MANAGEMENT_UNREACHABLE`, creates only a blocked audit, consumes no approval, and leaves the active profile unchanged.
12. **Bedrock and honest local doubles.** Real explanation uses `strands.models.BedrockModel(region_name=..., model_id=...)`, selecting `BEDROCK_INFERENCE_PROFILE` before `BEDROCK_MODEL_ID`, a no-tools agent, temperature `0.0`, and at most 600 output tokens. `DeterministicLocalExplainer` and `LocalTestDoubleModel` make no AWS/network call and identify as `LOCAL_TEST_DOUBLE`; a local-double run still calls the real Decider HTTP service. Component statuses are independently traced as Decider `REAL`, Strands dispatch `REAL`, explainer `REAL|LOCAL_TEST_DOUBLE`, and telecom `SIMULATED`.
13. **Trace contract.** Write ordered JSONL events for run/config hashes, observation, filtering, Decider health/request/response, decision policy, no-decision branch, Strands dispatch, proposal, preview/final gates, blocked audit or approval consumption/reservation, each transition state, duplicate suppression, both checks, explanation, and terminal result. Deterministic IDs link choice → effective choice → tool → proposal → transition → checks. External JSON with duplicate keys is rejected before validated payload tracing.
14. **Standalone reusable router.** `patterns/capability_aware_router/` is importable without `simshift` and contains typed question/options/filter/decision/no-decision/result/trace schemas, a 0–255 filter protocol, trusted engine-capacity input, canonical strict Decider HTTP client, registry router, non-telecom document-processing example using the real adapter, README, and independent tests. Test 0, 1, 2, 24, 25, and 255 eligible options against `num_slots=24`, malformed output, low confidence, forbidden labels, and exact dispatch; 25/255 must return typed non-dispatch results before HTTP.
15. **Reproducible packaging and commands.** Use CPython 3.11, `uv==0.12.18`, a `src/` layout, exact direct pins (`pydantic==2.14.1`, `strands-agents==1.61.1`, `pytest==9.1.1`, `ruff==0.17.1`, `mypy==2.4.0`, `cfn-lint==1.57.2`), committed `uv.lock`, and hash-locked CPU/CUDA deployment constraints. CLI commands are `run`, `policy-check`, and `validate-fixtures`. Default tests download no model/runtime data and need no credentials, Docker, native ShellCheck, or network.
16. **Reviewable AWS deployment assets.** Provide locally lintable CloudFormation, parameter examples, a non-circular offline artifact archive/file manifest, systemd units, bootstrap/preflight scripts, and least-privilege IAM intent for one x86_64 EC2 host in `eu-central-1`. The private subnet has no Internet dependency: artifacts come from one exact versioned S3 object and required S3, SSM, Logs, and Bedrock Runtime VPC endpoints are explicit/fatal preconditions. Interface endpoints require private DNS; the S3 gateway endpoint is verified by route table, regional prefix-list target, exact endpoint ID, and exact-version object request, not by private DNS answers. EC2 creation depends on endpoint/route readiness. Decider binds only to loopback. No deployment/provisioning command runs by default.
17. **Evidence, license, and data.** New source and pattern are Apache-2.0; preserve required notices for redistributed Apache artifacts. Inputs contain only bounded synthetic identifiers/values. No real telecom/customer data, geographic coordinates, credentials, real telecom action, benchmark claim, AWS claim, or success claim is accepted without corresponding raw evidence.

## Non-Functional Requirements

- **Safety and concurrency:** defaults deny. Proposal and transition IDs are deterministic. Gate passes are pure; one incident lock owns final recheck/atomic reservation. Approval is consumed only on successful commit. Simulator dispatch is idempotent and state mutation occurs once.
- **Reproducibility:** deterministic effects hash fixture revision, seed, action, occurrence, check, and device index. `run_id` hashes only behavior-affecting configuration; endpoints, trace paths, explainer choice, dependency metadata, and wall time use a separate `environment_evidence_hash`.
- **Security:** the MVP accepts only literal loopback Decider URLs; it rejects userinfo, query, fragment, redirects, and oversized bodies. Use a 2-second connect timeout, 30-second read timeout, and 64 KiB response cap. AWS uses roles and private endpoints, never static keys.
- **Observability:** safe denials are INFO, recoverable dependency retries WARNING, exhausted dependencies ERROR, and invariant/storage corruption CRITICAL. Model latency and total wall time are separate. Hidden truth and secrets never enter logs.
- **Testability:** schemas, filters, gates, effects, verification, and ID/hash functions are pure; repositories/adapters are injected. Unit tests use fakes only from `tests/`; integration tests are opt-in and never provision.
- **Performance:** no target or claim is imposed. GPU/CPU latency, throughput, and cost remain `UNVERIFIED` until measured on the selected AWS host.

## Acceptance Criteria

1. `uv sync --frozen --extra dev` succeeds in a clean Python 3.11 environment, and `uv run python -m simshift.cli validate-fixtures` validates both complete v1 fixtures and cross-field invariants.
2. `uv run pytest -q -m "not real_decider and not production_path and not aws_integration"` requires no network/model/AWS and passes deterministic seed/effect, structural truth-isolation, cardinality, stale revision, all gates, atomic commit, duplicate proposal/dispatch, approval consumption, transition, dual-check, bounds, and trace-link tests.
3. A parameterized unit test injects every admissible model label with `DecisionPolicy(min_confidence=0)`, proves `model_choice == effective_choice`, and proves exactly the matching registered Strands tool runs once with the current observation revision while both Bedrock and inert-model invocation counts remain zero.
4. A separate default-policy test injects a valid response below `0.20`, proves the original `model_choice` remains in trace, `effective_choice == escalate_or_wait`, override reason is `LOW_CONFIDENCE`, and only the escalation tool runs.
5. Router tests with trusted `num_slots=24` cover 0, 1, 2, 24, 25, and 255 eligible options: Decider is not called below two or above 24; 25/255 return `UNSUPPORTED_CHOICE_CARDINALITY`; no option is fabricated/reduced; and an unknown/stale response causes no dispatch or mutation.
6. `OFFLINE` tests prove retry/operator/profile evaluation are absent from the Decider request; a forced proposal returns `BlockedProposalAudit(MANAGEMENT_UNREACHABLE)`, keeps approval unconsumed, creates no transition lifecycle event, and preserves the active profile and counters.
7. `BR_PROFILE` unit tests prove the proposal is traced before scripted simulated approval creation; denied approval creates only a blocked audit; every run/proposal/incident/source/target mismatch and stale/consumed grant is denied; final-recheck denial cannot consume approval/reserve a key; and the bound granted path reaches `SUCCEEDED` only after distinct passing registration and telemetry events.
8. Structural leakage tests construct model projections only from `ObservableIncident` and reject every evaluator-only key/path, `HiddenCause`, serialized truth/effect object, private `_` key, and fixture-unique canary at Decider bytes, Bedrock bytes, tool input/result, JSONL, and logs. Public `Action`/`EvidenceCode` values remain valid when independently emitted by public DTOs.
9. With an already running pinned service and trusted manifest, `SIMSHIFT_RUN_REAL_DECIDER=1 STRANDS_DECIDER_URL=http://127.0.0.1:8099 STRANDS_DECIDER_MANIFEST=.artifacts/decider-manifest.json uv run pytest -q -m real_decider` validates exact `num_slots=24`, health identity and wire invariants, then uses `DecisionPolicy(min_confidence=0)` to prove the actual returned label invokes exactly its matching registered Strands tool without asserting a preferred semantic label.
10. `SIMSHIFT_RUN_PRODUCTION_PATH=1 STRANDS_DECIDER_URL=http://127.0.0.1:8099 STRANDS_DECIDER_MANIFEST=.artifacts/decider-manifest.json uv run pytest -q -m production_path` runs the bounded production coordinator with the exact documented BR projection/question, pinned model, default `0.20` policy, seed `20261018`, and a proposal-bound scripted simulated grant. It must trace `evaluate_profile_change` dispatch, all five final gate passes, `ENABLED`, distinct passing registration/telemetry checks, `SUCCEEDED`, and terminal `RESTORED`. The same marker runs exact `OFFLINE` seed `20261019` with the real Decider and requires terminal safe escalation, no transition record/lifecycle event, no approval consumption, and unchanged active profile. Any changed model route is a characterization failure requiring fixture/prompt review—not a skip or substituted fake success.
11. If `SIMSHIFT_RUN_REAL_DECIDER` or `SIMSHIFT_RUN_PRODUCTION_PATH` is absent, its marker skips exactly with `set <VARIABLE>=1`; once set, missing URL/manifest, artifact/health mismatch, connection failure, malformed response, or semantic production-path mismatch fails rather than skips.
12. `uv run python -m simshift.cli run --scenario BR_PROFILE --seed 20261018 --approval granted --decider-url http://127.0.0.1:8099 --decider-manifest .artifacts/decider-manifest.json --explainer local-test-double --trace-out .artifacts/br.jsonl` uses the exact production loop and real Decider. `--approval granted` is labeled `SCRIPTED_SIMULATED_INTENT` and becomes a grant only after proposal trace; only explainer/host model are `LOCAL_TEST_DOUBLE`, telecom is `SIMULATED`, and Decider/Strands dispatch are `REAL`.
13. `uv run python -m simshift.cli policy-check --scenario OFFLINE --seed 20261019 --action evaluate_profile_change --approval granted` exits 0 with machine-readable `BLOCKED`, reason `MANAGEMENT_UNREACHABLE`, no transition ID, no approval consumption, and no state mutation.
14. If `SIMSHIFT_RUN_AWS_INTEGRATION` is absent, AWS tests skip exactly with `set SIMSHIFT_RUN_AWS_INTEGRATION=1`; when enabled with explicit Bedrock/Decider/manifest configuration and authorized credentials, failures are not skipped and no provisioning occurs. The test first runs the exact BR production-path assertions from criterion 10 on the AWS host, then calls one real no-tools Bedrock explanation only after the completed public evidence; it also runs real-Decider `OFFLINE` and asserts no transition/profile mutation.
15. `uv run pytest -q patterns/capability_aware_router/tests` passes independently; the non-telecom example imports no `simshift` module and displays capacity, options, removals, `model_choice`, `effective_choice`, selected callback/non-dispatch result, and trace.
16. `scripts/build-offline-bundle.sh` followed by `uv run python scripts/verify-offline-bundle.py <archive> <external-metadata>` passes one build-then-verify round trip. External metadata supplies exact S3 version/archive SHA; internal `files.manifest.json` excludes itself and lists every other normalized regular file by path, size, and SHA-256; logical adapter/base artifacts reference explicit files or a defined Merkle root, never an unhashed directory.
17. `uv run ruff check .`, `uv run mypy src patterns/capability_aware_router`, `uv run python scripts/check_license_headers.py`, `uv run cfn-lint infra/ec2/cloudformation.yaml`, `uv run python scripts/validate_iam_intent.py infra/ec2/cloudformation.yaml`, `uv run python scripts/validate-artifact-manifest.py infra/ec2/artifacts/example-manifest.json`, and `bash -n scripts/*.sh` pass locally. ShellCheck is optional enhanced lint and is not part of zero-install acceptance.
18. Inspection confirms Decider has no non-loopback listener; infrastructure contains no credentials/account ID, wildcard Bedrock action, unverified model default, NAT requirement, or real telecom client; CloudFormation orders endpoint/routes before EC2; and no acceptance command initializes Git, deploys, provisions, publishes, or invokes a telecom system.

## Out of Scope

A UI/map, per-device agents, the other four scenarios, counterfactual dashboard, benchmark dataset/calibration study, real customer or telecom data, real carrier/eUICC/eIM/IPA/SM-DP+ integration, SGP.32 certification, device-side fallback, profile download, rollback, public hosting, Git initialization/commit/push/PR, cloud provisioning/deployment, article/video publication, and unsupported performance/cost/result claims are outside this slice.
