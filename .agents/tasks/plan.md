# Implementation Plan

Planning decisions: Phase 1 is the only implementation critical path: a runnable local Python 3.11 CLI using a real loopback Decider service, real Strands framework dispatch, deterministic simulated telecom behavior, and local/optional Bedrock explanation. AWS deployment hardening is recorded as a Phase 2 backlog and must not block local completion. Final profile-gate denial is terminal, and trace provenance separates the real Strands framework from its non-invoked local tool-host model and from the explainer model. Production code has no fake Decider; test doubles remain under `tests/`.
